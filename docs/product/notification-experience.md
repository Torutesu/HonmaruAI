# 通知・通知音・初回設定

## 初回の流れ

短い操作説明（省略可）→役割と言語→日報（任意）→通知と音→ワークスペース。
日報を後回しにするとチャンネルや定期実行は作らない。通知を許可しなくても開始できる。
許可要求は「通知をオンにする」を押したときだけ。Macではアプリ内の有効化、OSの許可、実際に通知が見えたかを別々に扱う。
テスト送信後は表示の有無を本人に確認し、届かなければシステム設定と集中モードを案内する。
保存に失敗したら完了扱いにせず、その場で再試行できる。戻る・完了ボタンは小さい画面でも届く位置に置く。

## 音の意味と初期値

| 出来事 | 操作中の音 | 初期値 |
| --- | --- | --- |
| 自分への依頼 | 上がる3音 | オン |
| 自分の依頼への回答 | 下がる2音 | オン |
| DM・メンション | 短い2音 | オン |
| 通話の着信 | 繰り返す着信音、最大30秒 | オン |
| 通常のチャンネル投稿 | 低い1音 | オフ |
| 閲覧中の会話への投稿 | 小さな短音 | オフ |
| 送信、通話への参加・退出 | 操作に応じた短音 | オフ |

既存の設定は変更しない。新規ユーザーは「重要な通知だけ」が初期値。
「音を鳴らさない」は表示通知を残して音だけを消す。試聴は明示的に押したときだけ鳴る（消音時も試聴可能）。
アプリ内音量の初期値は40%。通知の種類ごとの切替と音量調整を設定に残す。

## 配信と静けさ

- Macのバックグラウンドの依頼・回答・メンション通知は、Web Audioを鳴らさずOS通知音を使う。音量・集中モードはOSに従う。種類ごとの音色はアプリ操作中に適用される。
- OS通知にもアプリの消音・種類別設定を反映する。アプリ音量0は消音、それ以外のバックグラウンド音量はOS管理。
- 同じ重要度の連続到着は1.5秒内に1音。表示通知は消さない。小さな操作音の直後でも重要通知を優先できる。
- アプリの通知休止・通知時間外は着信音も抑える。OSの集中モードはWeb Audioに適用されないため、アプリ内着信音はアプリの休止設定で制御する。
- 複数タブは1タブだけが通知音を担当する（Web Locks対応環境）。
- Macアプリ終了中の配信は未対応。ウインドウを閉じた常駐状態では受け取れる。
- ブラウザーのWeb Push音はブラウザー・OS管理。ここでの音量・種類設定はアプリ内とMacデスクトップ通知に適用される。

## エージェントのスレッド境界

スレッド内の呼び出しは、親メッセージと呼び出し時点までの同じスレッド内の返信だけを読む。
別スレッド、チャンネルの他の投稿、削除済み投稿、後から届いた投稿や範囲外の引用は含めない。
長いスレッドでも親を残す。リンクの自動取得もこの履歴内に限定し、組織のプレイブックや個人会話の過去情報を自動追加しない。
チャンネル直下やエージェントとの通常の直接会話は従来の会話コンテキストを維持する。
