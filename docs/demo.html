TikTok for Work — インタラクティブデモ

iOSアプリの現機能をHTMLで再現した操作デモです。リレーサーバの挙動（AIルーティング・チャンネル・エージェント・ダイジェスト）はブラウザ内でシミュレートしています。実物はSwiftUI＋Node relayで動作します。

torutesu/honmaruai

試すシナリオ

  1. 「Tell your AI」に指示（例: Ask Bob to review the relay PR before Friday）→ ドラフト確認 → 送信
  2. 左上の名前でBobに切替 → カードが届いている
  3. カードを右スワイプで承認（Issue化）or ボタン操作
  4. カードのSourcesチップをタップ → 元になった会話や資料（Notion/GitHub）へワンタップ遷移
  5. Replyに自由文（OK, but release after Friday / Has auth signed off?）→ AIが意図を解釈
  6. Channelsで @ai file: Carol to polish the empty states → エージェントが会話から起票
  7. 「GitHub Webhook」→ PRレビュー依頼がカード化。✦ AIの推奨付きで届く（決裁履歴から学習）
  8. 推奨行をワンタップ → そのまま承認・Issue化
  9. 「SLAスイープ」→ 9時間放置のカードが上司(Alice)へエスカレーション
  10. 「ダイジェスト生成」→ 未読チャンネル活動がカード1枚に（受信者の言語で）
  11. 右上の⚙ → 設定画面。ダーク / ライトを切り替え（アプリ全体が即座に追従）

サーバ操作（シミュレート）

通知ポリシー: 鳴るのは pending × high/urgent のみ・接続中は鳴らない（デモではトーストで表現）

デザイン v2

深いインディゴブラック × アンビエントグロー、浮遊する角丸カード、グラデーションのプライマリ操作。ダーク/ライト両対応で、設定の外観トグルがアプリ全体（カード・チャンネル・シート）に即時反映されます。トークンは実装の Theme.swift と同じ値です。

言語レイヤー

Alice = 日本語 / Bob・Carol = English。カード・決裁結果・質問・ダイジェスト・AI推奨は受信者の言語で届き、🌐チップが翻訳配信を示します。BobがEnglishで承認した結果は、Aliceには日本語で届きます。

実装との対応

指示のトリアージ — relay /ai/ingest（決裁→カード、近況→チャンネル自動振り分け） 自由文リプライ — /ai/reply（条件付き承認・理由付き却下・質問・メモ） @aiエージェント — チャンネル常駐、file_decisionツールで起票 ダイジェスト — /digest/run、priority low＝通知なし ソース遷移 — card.sources（会話＝該当メッセージへスクロール／Notion等のURL自動抽出） 翻訳配信 — deliverCard()が受信者言語へAI翻訳（translate.js） GitHub流入 — /github/webhook（HMAC検証、レビュー依頼/アサイン/CI失敗） エスカレーション — /escalations/run、managesエッジを辿って上司へ AI推奨 — 決裁履歴メモリ（memory.js）→ ワンタップ追認 外観設定 — AppearanceMode（System/Dark/Light）＋適応型トークン Mac / Web — docs/CROSS_PLATFORM.md（薄いクライアント設計） 音声入力 — 実機はSpeech framework（デモではマイクが例文を入力）
状態はブラウザ内のみ。GitHub Issue番号・AI応答はデモ用の擬似値です。
