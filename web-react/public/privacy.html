プライバシーポリシー

最終更新日: 2026年10月8日

取り扱う情報

メールアドレス、氏名、アカウントID、プロフィール、ワークスペースへの所属を、ログインとチーム機能のために取り扱います。パスワードはハッシュ化して保存します。決定カードの件名・本文・背景情報・コメント・操作履歴、AIへの入力、接続したサービスから取得した情報を、依頼の整理、担当者への共有、履歴の表示に使用します。通知を有効にした場合は端末のプッシュトークンや通知設定を保存します。購入機能を利用する場合は購入履歴と購読状態を取り扱います。

Android アプリ

Android 版では、メールアドレスによる認証、ワークスペースへの参加、チャンネルとスレッドのメッセージ共有を提供します。メッセージ本文、投稿者、投稿日時、チャンネルへの所属、既読位置を、会話の表示と未読管理のために保存します。Android 版に音声入力、撮影、アプリ内購入の機能はありません。

音声と添付ファイル

iOSアプリの音声入力はAppleの音声認識を使い、端末内だけで文字起こしします。端末内認識に対応しない端末や言語では文字入力を使用します。マイク音声をAppleのサーバー、OpenAI、当社サーバー、チームメンバーに送信することはありません。AI下書きを選び、確認画面で許可した場合に、文字起こししたテキストと必要な仕事の文脈をOpenAIへ送信します。AIを使わず下書きすることもできます。撮影する動画は無音で、利用者が添付操作を行った場合のみアップロードします。カードに添付された画像・動画などは、共有と表示のために保存されます。

外部サービスとAI

Cloudflareをホスティング、データ保存、通信に使用します。AIによるカード生成や分類では、入力文、必要なチーム情報や文脈、接続サービスから取得したメッセージ等をOpenAIに送信します。AIの結果は誤ることがあるため、共有前に確認してください。メールのログインコードと通知はResend、プッシュ通知は、iOS ではApple、Android の通知機能ではGoogle の Firebase Cloud Messaging を使用します。通知を許可すると配信用の端末トークンを取得して当サービスに登録します。購入機能が有効な場合はAppleおよびRevenueCatで購読状態を管理し、RevenueCatのアカウント識別子を当サービスのIDと対応付けます。クレジットカード番号は当サービスでは取り扱いません。

AIへの送信と許可

iOS 1.3.0以降ではワークスペースを開く前に、送信するデータ、送信先、利用目的を表示して許可を確認します。許可するまでワークスペースの自動翻訳・要約などを開始しません。許可しない場合はサインイン画面に戻り、外部AIへ送信しないデモを利用できます。許可はそのサインイン中に有効で、サインアウト後は次のサインイン時に再確認します。既にチームへ共有した内容の保存や、他のメンバーが開始する処理まで取り消すものではありません。

AIへの入力は、利用者が入力・投稿・添付した内容、プロフィールやチーム設定、利用者が接続を許可したサービスから取得します。質問、依頼の整理、下書き、翻訳、要約、関連情報の検索、添付の解析に必要な範囲で、文章、文字起こしのテキスト、関連メッセージ、決定履歴、氏名・役割などのチーム情報、仕事の文脈、添付内容を送信します。これらに含まれる個人情報も処理対象です。

通常のAI処理にはOpenAIを使用します。ワークスペースの構成によってOpenRouterと選択されたモデル提供者、追加のAIエージェントにはAnthropic（Claude）、動画解析にはGoogle（Gemini）が使用される場合があります。第三者への送信は機能の提供に必要な目的に限定し、暗号化通信を使用します。提供者の契約・データ保護条件に基づき、機密保持、安全管理、目的外利用の制限など、本ポリシーと同等以上の個人情報保護を求めます。各社の保持期間や不正利用監視の扱いはサービス・設定によって異なり、即時削除や保持ゼロを一律に保証するものではありません。OpenAIのデータ保護、Anthropicのプライバシー情報、OpenRouterのプライバシーポリシー、Gemini APIの利用条件もご確認ください。

接続サービス

利用者が接続を許可したGmail、Slack、Notion、Google Calendar、Google Driveなどの情報を、許可された範囲で取得し、依頼の抽出やカードの作成に使用します。これらの接続はComposioを介して管理します。GitHub連携を使うワークスペースでは、リポジトリ情報や協力者情報の取得、承認後のIssue作成などを行います。接続の解除はアプリの接続設定、または各サービスの権限設定から行えます。

チーム内での共有

同じワークスペースのメンバーには、そのワークスペースのカード、関連する内容、決定履歴が共有されます。カードの宛先指定は、他のメンバーから内容を非公開にする設定ではありません。共有する権限がある情報だけを入力してください。

保存と削除

アカウント、カード、履歴はサービス提供に必要な期間保存します。アプリのプロフィール設定を開き、「アカウントを削除」で削除を実行できます。削除時はアカウント、セッション、所属、保存した設定、通知用トークンなどを削除します。あなた宛てのカードは削除し、他のメンバーに送ったカードと共有の操作履歴は、送信者・操作者のIDを匿名化して残す場合があります。カード本文に記載された氏名などが自動的にすべて除去されるわけではありません。外部サービスに作成されたIssue等や購読は、各サービスでも管理してください。Android ではチャンネル一覧の「Delete account」から削除できます。共有チャンネルの投稿は投稿者の識別情報を匿名化して、ワークスペースで当該記録が削除されるまで保持する場合があります。アプリを利用できない場合や追加の削除依頼は、アカウント・データ削除の手順から窓口へご連絡ください。

監査ログ

ワークスペースの管理者が安全に運用できるよう、ログイン、メンバーや権限の変更、設定の変更などの操作を監査ログに記録します。記録には操作した人と対象の人、日時、接続元のIPアドレスと端末の種類を含みます。メッセージの本文は記録しません。監査ログのうち人を特定できる部分は、ワークスペースごと・人ごとの鍵で暗号化して保存します。アカウントを削除すると、その人の鍵を破棄します。記録そのものは改ざんの検出のために残りますが、誰の操作だったかは当社を含め誰にも読めなくなり、仮名（p_で始まる識別子）だけが残ります。

広告・トラッキング

広告配信、個人データの販売、他社のアプリやウェブサイトをまたぐ広告目的のトラッキングは行いません。通知やマイクの権限は端末の設定から変更できます。
